# Modern-Login-page

> A beautiful, modern and responsive animated login / signup page with sliding panel animation. Made with pure HTML, CSS and JavaScript.

---

## Features

- **Animated Sliding Panel** - Smooth transition between Sign in and sign up
- **Modern Glass Desgin** - Routed corners with 30px curved overlay
- **Social Login Icons** - Google, Facebook, Github, LinkedIn
- **Form Validation** - Checks empty fields and email formet
- **LocalStorage Support** - Saves user after signup and auto-login
- **Fully Respnsive** - Works on mobile, tablet and desktop
- **No Framework** - Only HTML, CSS, JS

## How It Works

- Two forms (sign-in / sign-up) are placed absolute
- Blue toggle container slides with `transform: translateX();`
- Clicking SIGN IN removes `.active` class
- CSS `transition: all 0.6s ease-in-out` does the animation
